一条命令安装到 macOS。

安装脚本会下载最新发布版，把 CronBox.app 放进 /Applications，并把 cronbox 命令链接到一个可写的 bin 目录。

install macOS 
curl -fsSL https://raw.githubusercontent.com/xiaoxiunique/cronbox/main/scripts/install-macos.sh | bash

open /Applications/CronBox.app
cronbox help

为本地运维脚本而设计。

CronBox 更像一个轻量的本地控制台，而不是普通 cron 编辑器。它关注入口扫描、运行状态、日志、历史和可恢复性。

01

选择式入口扫描

目录添加默认先预览，用 --include 或 --all 决定哪些脚本进入 CronBox。

02

重复与 one-shot

支持标准 cron 表达式，也支持触发一次后自动禁用的 --once 调度。

03

实时日志

进程还在运行时，stdout 和 stderr 就会持续写入任务历史。

04

通知和重叠保护

调度完成后发 macOS 通知；上一轮还没结束时自动跳过下一轮。

像调度脚本一样调度 coding agent。

CronBox 可以创建 Codex 和 Claude Code 任务脚本。默认工作区保存 AGENTS.md 和 CLAUDE.md，让定时执行的 agent 行为保持一致。

工作区 Agent 任务默认从 ~/.cronbox 运行。
规则 AGENTS.md 和 CLAUDE.md 会和生成的任务放在一起。
Claude Code skill 运行 cronbox skills install，把 CronBox 调度能力交给 agent 使用。
codex 任务 claude 任务 日志

可以从 App 或终端管理。

桌面 App 会在可行时自动安装配套的 cronbox 命令，这样本地自动化不打开 UI 也能脚本化管理。

终端
cronbox add ~/scripts --include daily-report.py
cronbox add ~/scripts/cleanup.sh --alias "Clean temporary files"
cronbox schedules add ./daily-report.py "0 9 * * *" --tz Asia/Shanghai
cronbox schedules add ./reminder.sh "* * * * *" --once
cronbox jobs list
cronbox run ~/scripts daily-report.py --args '{"date":"today"}'

一个紧凑的本地周期任务闭环。

CronBox 把操作路径压短：扫描、调度、看日志、查历史、调整，然后重复。

1

添加目录

把 CronBox 指向脚本目录，只把真正需要调度的入口加入列表。

2

配置调度

别名、cron 表达式、时区、JSON 参数和启用状态都在一个地方编辑。

3

看日志和历史

详情页以日志为核心，把输入、历史、结果和输出放在同一个上下文里。
