# Changelog

All notable changes to CronBox will be documented in this file.

This project follows the spirit of Keep a Changelog and uses semantic version tags when release artifacts are published.

## [Unreleased]

### Added

- Local menu bar scheduler for runnable script entrypoints.
- Script aliases, cron expressions, timezones, JSON args, enabled state, and run history.
- Live stdout and stderr streaming into job logs.
- History-first script detail view.
- CLI management through the `cronbox` command.
- Codex and Claude Code task generation under `~/.cronbox`.
- GitHub Actions packaging for macOS, Linux, and Windows.
- Static Cloudflare Pages-ready project site under `sites/cronbox`.
